# create-runex-svelte

Scaffolds a Svelte app rendered by Rune through [runex](https://www.npmjs.com/package/runex-js),
with [@runex-js/svelte](https://www.npmjs.com/package/@runex-js/svelte).

```sh
npm create runex-svelte@latest my-app
cd my-app
npm install
npm start
```

With Bun: `bun create runex-svelte my-app`. Needs Node 24+ or Bun 1.4+ on ARM64 macOS, Linux or Windows.
